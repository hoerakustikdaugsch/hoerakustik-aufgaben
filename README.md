# Hörakustik Daugsch · Portal

Interne Web-App (PWA) für Hörakustik Daugsch: Start-Dashboard und Aufgaben, später Beratung, Preise und Kalender.

- Live: https://hoerakustikdaugsch.github.io/hoerakustik-aufgaben/
- Daten: Supabase (Frankfurt), Zugriff nur nach Anmeldung
- `supabase-setup.sql`: Tabellen und Zugriffsregeln
- Updates: Änderungen auf `main` werden von GitHub Pages automatisch veröffentlicht; installierte Apps laden die neue Version beim nächsten Öffnen.
